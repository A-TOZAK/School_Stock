# 授業テロップ

話したことが画面の下に字幕（テロップ）で出て、1行ずつ残る道具。
耳で聞くだけでは流れて消える言葉を、目でも追えるようにする。© School Stock

- 本体：`index.html` 1ファイル（依存ライブラリなし・ブラウザで開くだけ）
- 認識：Web Speech API（Chrome前提・日本語のみ・翻訳なし・話者識別なし）
- 文節折り：Chrome内蔵のBudouX（`word-break: auto-phrase`）
- ログ：localStorageに保存・クリックで訂正・.txt書き出し・「AIでまとめる」コピー
- 前に出す：Document Picture-in-Picture（テロップだけの小窓を最前面に）
- 検証用：`?demo=1` でマイクなしのデモが自動で動く。`?size=xl&theme=yellow&view=telop&open=set` のように見た目・モーダルをURLで指定できる（URL指定は保存されない）

## 先行ツールと出典

- 先行例：音声認識字幕ちゃん（西村良太氏・MITライセンス https://github.com/sayonari/jimakuChan ）。
  機能構成（区切り待ち・認識中表示・辞書・伏字）を学び、コード・デザインは使わず新規に実装した。
  完全無料・収益化利用可の公開ツールであり、本ツールは「教室向けに機能を絞った別物」。
- 設計判断の根拠（2026-08-29に読み込んだ研究。要旨は事業ノート同日版）：
  - 認識中テキストの書き換えチラつきは読み手の疲労と相関 → 描画250ms間引き・表示済み文字を動かさない（CHI 2023 "Text Stability in Live Captions"）
  - 字幕は16字×2行・約5字/秒が読める上限 → テロップにmax-width・既定2行・読み残しはログで（特殊教育学研究1985・NHK基準300字/分）
  - キーワードの誤認識が致命的・助詞の誤りは軽微 → 置きかえ辞書を最優先機能に（ASSETS 2017）
  - 自動の文章整形は成功3割・悪化もある → 勝手に書き換えない。直すのは人（クリック訂正）とAIまとめの後段（人工知能学会論文誌37-3, 西村ら2022）
  - 話し方で認識率40→80% → 話し方のコツ6箇条を「つかいかた」に同梱（皆川ら2016）
  - 認識率98%のNHKでも人手修正を外さない → ログ訂正動線は必須（NHK技研取材2018）
