# School Stock アクセスカウンター 設定手順

サイトの「見られた数」と「ダウンロードされた数（＝人気素材）」を測るしくみです。
コード側は全部できています。**あなたがやるのは Supabase を用意してキーを2つ貼るだけ**です。
（Cookieなし・個人情報なし・無料枠で十分）

## やること（10分ほど）

### 1. Supabase のプロジェクトを作る
- https://supabase.com にアクセス → GitHubアカウントでサインアップ/ログイン
- 「New project」→ 名前（例: school-stock）とパスワードを決めて作成
- できるまで1〜2分待つ

### 2. SQLを貼って実行
- 左メニュー **SQL Editor** → 新規クエリ
- このフォルダの **`counter-setup.sql`** の中身を丸ごと貼り付け → **Run**
- 「Success」と出ればOK

### 3. キーを2つコピーして貼る
- 左メニュー **Project Settings → API**
- 次の2つをコピー：
  - **Project URL**（例: `https://abcdefgh.supabase.co`）
  - **anon public** キー（`eyJ...` で始まる長い文字列）
- `assets/counter-config.js` を開いて、この2つを貼る：
  ```js
  window.SS_COUNTER = {
    url: "ここにProject URL",
    key: "ここにanon public キー"
  };
  ```
  ※ anon public キーは公開して大丈夫な種類です（RLSで守っています。service_role キーは絶対に貼らない）

### 4. commit & push
- 変更した `counter-config.js` を push（数分でサイトに反映）
- これで計測開始。以後どのページでも自動でカウントします

## 見る場所

- 集計ページ：**https://a-tozak.github.io/School_Stock/stats/**
  - **全体の数字** … のべ表示数・のべダウンロード数・持ち帰り率（表示100回あたり何回保存されたか）・スマホ率・目印つきの訪問数
  - **日ごとの動き** … 14日／28日／90日の棒グラフ（90日は1週ごとにまとめて表示）※下の「日づけ別」を入れたときだけ出ます
  - **棚ごとの成績** … prints・lab・sozai …と棚べつに、表示・DL・持ち帰り率をならべる
  - **よく見られた・よく持ち帰られた** … ページ／ダウンロードの上位20をページの題名で表示
  - **ダウンロードの中身** … 形式べつ（PDF・ZIP・画像）と棚べつの内わけ
  - **どこから来て、何で見ているか** … `?from=` の目印べつの流入元と、スマホ／パソコンの割合
  - **明細（全データ）** … 全キーをさがせる表。CSVに書き出せる
- このページは検索に出ない設定（noindex）で、メニューにも載せていません。URLを知っている人だけ見られます

## ページの題名を出すための一手間（ページを増やしたら）

集計に貯まるのは住所（`/School_Stock/lab/07-goi-fusoku/`）だけなので、
そのままだと集計ページが住所の羅列になります。次のコマンドで対応表を作り直してください。

```
python3 _build/build_pagemap.py
```

→ `stats/pagemap.json` が更新されます（各ページの `<title>` から自動で作ります）。
**新しいページを足したら、これを実行して一緒にコミット**すれば、集計ページに題名で並びます。

## 日づけ別も貯める（あとから足せる・任意）

いまの `counts` は「はじめてからの合計」だけなので、「先週とくらべてどうか」が見えません。
見たくなったら：

1. Supabase の SQL Editor に **`_setup/counter-daily.sql`** を貼って Run
2. `assets/counter-config.js` に `daily: true` を足す
   ```js
   window.SS_COUNTER = { url: "...", key: "...", daily: true };
   ```
3. push → 翌日から集計ページに「日ごとの動き」のグラフが出ます

貯まっている合計はそのまま。順番をまちがえて `daily: true` だけ先に入れても、
自動で今までのやり方に戻るので計測は止まりません。

## 仕組み（かんたんに）

- `assets/counter.js` … 全ページに読み込み済み。ページ表示とダウンロード（保存ボタン）を1回ずつ数える
- `assets/counter-config.js` … あなたがキーを貼るファイル（ここだけ触ればいい）
- Supabaseの `counts` テーブルに「key（住所）」と「n（回数）」だけ貯まる
- 書き込みは `bump()` 関数だけ・読み取りは数字だけ公開 → 荒らされにくい

困ったら「counterの設定でつまずいた」と言ってください。一緒に直します。
