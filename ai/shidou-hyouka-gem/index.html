01WHAT

どんな Gem なのか

ひとことで言うと、授業の振り返りを貼ると、学級全員分の学習評価レポートを1枚のHTMLで返してくる Gem です。Gemini の Gem（あらかじめ役割と手順を仕込んだ相棒）として作られていて、共有リンクから誰でも使えます。

返ってくる画面は、次の4つでできています。

  • 本時の主眼（推論）……この時間で何をねらっていたのかを、子どもの記述から推し量って冒頭に置く
  • 提出率と未提出者……名簿と突き合わせて、出していない子を名指しで出す
  • 3つのフィルタ……「支援が必要」「次時ピックアップ」「通常」で全員を仕分ける
  • 一人1枚のカード……観点と評価（A／B／C）、その理由、児童の記述そのまま、分析、次時の声かけ

作りとして効いているのは、次の4つです。どれも Gem の指示に書き込まれています。

  • 名寄せ：ひらがなと漢字の違い、空白の有無を吸収して名簿に紐づける。だから未提出者が確実に出る
  • 観点を選ぶ：3観点すべてを無理に埋めない。その記述に最も強く表れている観点を1つ2つだけ選ぶ
  • 生データを触らない：子どもの記述は要約も修正もせず、そのまま載せる
  • 全員を出す：省略しない。人数分のカードを必ず作る

出てくるのは画面ではなくHTMLのコードなので、Canvas で開けばその場で表示され、ダウンロードして Google サイトに貼ることもできます。作者本人が勧めているのはその使い方です。

使う前の設定は2つだけ

出力は Canvas。これは必ず入れてください。モデルは Gem の説明文に Pro と書かれていますが、Flash でも十分に動きます。むしろ速い。この記事の最後で、同じ入力を両方に投げて比べた結果を載せました。

02WHO

どんな人におすすめなのか

この Gem が効くのは、振り返りをすでに集めている先生です。集める仕組みがある人ほど、読めずに溜まっている量も多いからです。

  • 毎時間フォームで振り返りを集めているが、目を通せないまま次の日が来る
  • 所見や評価の根拠が印象に寄りがちで、事実の形で残しておきたい
  • 次の授業の導入で誰の記述を紹介するか、直前に名簿を眺めて決めている
  • 複式や少人数で、間接指導の時間に一人ひとりを見きれない
  • 研究授業のあと、子どもの記述を分析して書く時間が取れない

逆に、次の場合はいったん見送ったほうがいいと思います。

  • 振り返りが一言で終わる学級……「楽しかった」だけの記述からは、AIも何も読み取れません。まず書かせ方のほうを変える必要があります
  • 通知表の評定を決めたい……これは次の一手を決めるための道具です。総括的な評定の証拠としては使えません
  • 児童名をそのまま入れられない環境……自治体のルールが先です。出席番号での運用に置き換える必要があります（この記事の最後で触れます）
読めなかった記述が読めるようになる道具ではなく、読んだあとの判断を早くする道具です。
03HOW

実際の使い方

操作は3手です。校種も教科も関係なく同じです。

  1. Gem を開く共有リンク（gemini.google.com/gem/137c7d778700）から開き、＋のメニュー →「その他のツール」から Canvas を選ぶ。モデルは Flash のままで構いません（理由は最後の章に）。
  2. 名簿と振り返りを貼るフォームの回答をコピーして、そのまま貼りつける。名簿は最初の1行にまとめて書く。
  3. 出てきた画面を読むCanvas に一覧が出る。フィルタを押して、支援が必要な子とピックアップしたい子を確かめる。

ここからは、実際に投げて出てきた画面をそのまま載せます。児童名・生徒名と記述はすべて架空のものです。

CASE 1｜小学校
小学4年 理科「とじこめた空気と水」／28人

めあてを書かずに投げてみる

1つ目は、あえてめあてを書かずに投げました。この Gem は、めあてが書かれていないとき、記述の中身からその時間のねらいを推し量る作りになっているからです。そこが本当に効くのかを見ます。

貼ったのは、名簿28人と、振り返り26件だけです。2人ぶんは、わざと抜いてあります。

実際に貼ったもの（先頭だけ抜粋） 
今日の授業の振り返りログです。分析をお願いします。

【今回のマスター名簿（28名）※Gem設定の名簿より、こちらを優先してください】
あおき ゆうと, いしい さくら, うえだ はると, えんどう みゆ, …（28名）

【振り返りログ】
1,あおき ゆうと,空気はおすとちぢんだけど、水はおしてもぜんぜんちぢまなかった。ちゅうしゃきのぼうがびくともしなかったのがびっくりした。空気にはすきまがあって、水にはすきまがないのかなと思った。
2,いしい さくら,水はちぢまなかった。空気はちぢんだ。
3,うえだ はると,おしたら手がいたくなった。たのしかった。
…

ここが、この Gem のいちばん強いところです。めあてを打ち込む手間すら要らない。振り返りを貼れば、その時間が何をねらっていたかは記述の側から立ち上がってきます。

読みどころを3つだけ挙げます。

「すきま」に気づいた子を拾っている

空気にはすきまがあって、水にはすきまがないのかなと思った。（あおき ゆうと）

これに対して「空気と水の違いを『すきま』という言葉でモデル化して捉えようとする素晴らしい視点です」と価値づけ、次時の声かけとして「『すきま』があるかどうか、絵に描いてみるともっと分かりやすそうだね！」を返してきました。小学4年では粒子の考え方は扱いません。それを承知したうえで、子どもの言葉のまま次につないでいます。

誤って捉えた子を、C で拾っている

水もちょっとだけちぢんだ気がした。目もりが少し動いたと思う。（かとう ひなた）

これを知識・技能の C とし、理由に「微細な動きを『縮んだ』と誤認しており」と書いています。同じ「支援が必要」でも、うえだ はると（おしたら手がいたくなった。たのしかった。）とは、つまずきの種類がまったく違う。それが理由の文で区別できます。

ただし、ピックアップが多すぎる

この Gem をそのまま回すと、良い記述をよく拾ってくれる代わりに、絞ってはくれません。対処は簡単で、そのまま続けて一言足します。

続けて投げる一言 
HTMLの作り直しは不要です。文章だけで答えてください。
次時の導入で紹介するなら、誰を3人、どの順で紹介しますか。順番の理由も書いてください。
CASE 2｜中学校
中学1年 国語 説明的な文章／16人

めあてと評価規準を一緒に渡す

2つ目は逆に、めあてと本時の評価規準を最初から渡しました。Gem の指示には「アップロードされた資料がある場合は、それを評価の根拠として最優先する」と書かれています。手元の指導案からコピーして貼るだけで効きます。

実際に貼ったもの（先頭だけ抜粋） 
中学1年 国語の授業ログです。分析をお願いします。

【本時のめあて】筆者が挙げた具体例が、主張とどうつながっているかを説明する

【本時の評価規準】
知識・技能：具体と抽象など情報と情報との関係について理解している。
思考・判断・表現：「読むこと」において、具体例と筆者の主張との関係をとらえ、
文章の構成や論の展開について考えている。
主体的に学習に取り組む態度：進んで文章の構成をとらえ、学習課題に沿って
考えを説明しようとしている。

【今回のマスター名簿（16名）】…

ここは先生が見直したほうがいい

16人のうち、次の記述が「通常」に置かれました。

人は無意識に一つの見方を選んでいる、という部分が心に残った。自分も友達を一面だけで決めつけていたかもしれないと思った。（鈴木 隼人）

本時のめあては「具体例と主張のつながりを説明する」なので、その物差しで見れば妥当な置き場所です。ただ、読んだことを自分の生活に引き戻している記述でもあります。情意の方に振れた記述は、ねらいの物差しからは外れて見える。ここを拾うかどうかは、AIではなく先生が決めるところです。

逆に、次の記述は「支援が必要」に入りました。

絵が二通りに見えるのは知っていた。だから読むのは楽だった。（篠原 葵）

知っていたから楽だった、で止まっていて、めあてに向かっていない。これは納得のいく判断でした。

CASE 3｜高等学校
高校2年 数学II「三角関数の合成」／12人

C 評価の中身を分けさせる

3つ目は高校です。数式が入る教科でも、記述さえあれば同じように動きます。

C がついた子の中に、できている子がいる

公式は覚えた。r=√(a²+b²) で計算はできる。なぜそうなるかは考えていない。（五十嵐 千夏）

これに Gem がつけた評価は「思考・判断・表現（C）」でした。本時のめあてが「なぜ成り立つかを説明する」だったので、その物差しでは確かに C です。けれど知識・技能で見れば、この子はできています。観点をひとつ選ぶ設計の裏返しで、できている面が画面から消えます。

C を見たときに「この子は分かっていない」と受け取ってしまうと、事実を取り違えます。だからここでも、続けて一言投げます。

続けて投げた一言（全文） 
ありがとうございます。HTMLの作り直しは不要です。文章だけで答えてください。

1. 次時の導入で記述を紹介するなら、誰を3人、どの順で紹介しますか。順番の理由も書いてください。
2. その3人をどう紹介すれば、まだ分かっていない子の助けになりますか。教師の言い方の例をそれぞれ1文で。
3. C評価をつけた生徒のうち、つまずきの種類が違う子を分けて教えてください。
   同じ声かけでよい子と、別の声かけが要る子はどう分かれますか。

返ってきたのが、この記事でいちばん実用的な部分でした。

返ってきた答え（抜粋・原文のまま）

【紹介する順番】① 浅井 涼介さん → ② 窪田 莉子さん → ③ 江口 美桜さん

【順番の理由】数学的な理解を「既習事項の想起」→「式変形の理屈（代数）」→「視覚的な意味（幾何）」というステップで広げていくためです。まず、浅井さんの記述で「全く新しい公式ではなく、知っている加法定理の逆再生である」という安心感を与えます。（中略）最後に、江口さんの「座標上の点 (a,b)」という図形的な視点を紹介することで、抽象的な式を視覚化し、内海さんのような「角度 α の決め方が分からない」という生徒のつまずきを解消する流れを作れます。

紹介する順番に、授業としての筋が通っています。しかも、その順番が誰のつまずきを解くためのものかまで書かれている。「浅井→窪田→江口の順で紹介すれば、内海のつまずきに届く」という話になっています。

C の分け方も同じように返ってきました。

C評価の分類（抜粋・原文のまま）

【グループA：既習事項の定着不足・計算手順のミス】近藤 奏太、小泉 悠。
声かけの例：「合成の計算をする前に、まずは加法定理の公式をメモして、問題の式と上下に見比べてから a と b に丸をつけてみようか。」

【グループB：幾何的意味への変換でのつまずき】内海 洋輔。
声かけの例：「式だけで α を探そうとすると混乱するから、まずは横軸に a、縦軸に b を取って点をおき、直角三角形を描いてみよう。」

【グループC：全体的な思考停止・手が止まっている】菊地 悠斗、五十嵐 千夏。
声かけの例：「『分からない』と言えたのは素晴らしいね。加法定理の逆再生まではピンとくる？ それとも、最初の式の意味から一緒に確認してみようか。」

同じ C でも、声のかけ方が3通りに分かれました。ここまで来ると、翌日の授業で誰の席にどの順で行くかが決まります。

うまい使い方と、微妙な使い方

3回動かして分かったことを、そのまま並べます。

うまい使い方
  • めあてと評価規準を一緒に貼る。指導案からコピーするだけで、返ってくる言葉が指導案と揃います
  • 1回で終わらせず、続けて一言足す。「3人に絞って」「順番の理由も」「Cのつまずきを分けて」。この一言が、レポートを明日の動きに変えます
  • 未提出者の欄をいちばん先に見る。名寄せが効いているので、ここは正確です。出していない子に気づくのが、いちばん早い支援になります
  • 放課後に投げて、置いておく。人数が多いと数分かかります。待つ時間ではありません
  • ダウンロードして残す。Canvas の画面は流れます。HTMLで落として単元のフォルダに置けば、研究授業の記録になります
微妙な使い方
  • 出てきた評価を、そのまま評定に使う。これは次の一手を決めるための見立てで、成績の証拠ではありません
  • 「次時の声かけ」をそのまま子どもに言う。あれは下書きです。その子との関係の上に置き直すのは先生の仕事です
  • ピックアップを全員紹介しようとする。28人で9人出ました。絞るところまでは Gem はやってくれません
  • C を「分かっていない子」と読む。観点をひとつ選ぶ設計なので、できている面は画面から消えます
  • 一言だけの振り返りを大量に投げる。「楽しかった」からは何も出ません。もっともらしい分析が付くぶん、かえって危ない
  • 数式の多い教科で、何も足さずに Flash で回す。数式が $\tan\alpha$ のような書き方のまま画面に出ます。一言足せば直ります（次の章）
  • Canvas を切ったまま投げる。コードが会話の中に長々と流れるだけになります。ここは Pro／Flash に関係なく必須です
04SETUP

自分の学校・学級・授業用にカスタマイズする

ここまでは、共有された Gem をそのまま借りて、名簿を毎回貼る形で使ってきました。毎日使うなら、名簿は Gem 側に焼いてしまったほうが早いです。手順は6つです。

  1. Gem を自分のものにコピーする共有リンクから開いた Gem は、そのままでは中身を書き換えられません（下の画面のとおり、「共有アイテム」の鉛筆マークはグレーのままです）。左のメニューから Gem マネージャー を開き、「共有アイテム」の中の「指導と評価の一体化支援Gem」の右端 ⋮ から 「コピーを作成」。これで「マイ Gem」に入り、編集できるようになります。
  2. 名簿を書き換えるGem の指示文には [クラス人数] と [児童名1]…[児童名32] という空欄があります。ここを自分の学級に置き換えます。人数の数字は3か所に出てくるので、全部そろえてください。
  3. 評価規準表を「知識」に入れる単元の目標や評価規準表をPDFで持っているなら、Gem の「知識（Knowledge）」に入れておきます。毎回貼らなくても、評価の根拠として最優先で使われます。
  4. Pro と Canvas を毎回選ぶこの2つは会話ごとの設定なので、新しい会話を始めるたびに選び直します。忘れると出力が変わります。
  5. 置き場所を決める作者が勧めているのは Google サイトです。単元ごとのページを作って、出てきたHTMLを埋め込んでいく。学年で共有するなら、この形がいちばん軽い。
  6. 振り返りの書かせ方を1つだけ変えるこれが実はいちばん効きます。「分かったこと」だけでなく「なぜそう言えるか」を書かせる。理由が書いてある記述からしか、根拠のある評価は返ってきません。
書き換えるのはここ（Gemの指示文の一部） 
【マスター名簿（[クラス人数]名）】

[児童名1], [児童名2], [児童名3], … [児童名32]

※照合ルール：空白削除、ひらがな/漢字の読み替え、部分一致を用いて
「最も近い児童」に紐付け。

教科によって、足しておくと効く一文

Gem の指示はそのままに、会話の最初に一文足すだけで、教科の癖に寄せられます。

  • 理科：「誤った捉え方をしている記述は、どこを誤解しているかを具体的に書いてください」
  • 国語：「本文のどの語を根拠にしているかが書かれているかどうかで、評価を分けてください」
  • 算数・数学：「知識・技能と思考・判断・表現の両方を、それぞれ別に評価してください」
  • どの教科でも：「次時ピックアップは3人までに絞り、紹介する順番をつけてください」
個人情報の線引き

この Gem は名簿を使う設計なので、そのまま使えば児童生徒の実名を生成AIに入れることになります。自治体や学校のルールが先です。実名を入れられない場合は、名簿を出席番号だけにして、振り返りも番号で貼る形になります。ただしこの Gem の名寄せは、ひらがなと漢字の揺れを吸収するために作られた仕組みです。番号だけの運用で同じ精度が出るかは、この記事では確かめていません。まず自分の学級の1時間ぶんで試してから、日常の運用に入れてください。

あわせて、出てきたHTMLの置き場所にも気をつけてください。子どもの記述がそのまま入っています。Google サイトに埋め込むなら、公開範囲を必ず限定にします。

道具が返してくるのは見立てまでです。誰にどう声をかけるかを決めるのは、その子を知っている人だけです。
05PRO vs FLASH

Pro と Flash、どちらで回すか

Gem の説明文には「Pro を選び」と書かれています。ただ、Pro は無料で使える回数に限りがあります。毎時間の振り返りに使うなら、そこが一番の壁になる。そこで、まったく同じ入力を Pro と Flash の両方に投げて比べました。高校2年 数学IIの12人分、CASE 3 と同じデータです。

結果

  • 時間：Pro は5〜6分。Flash は約1分。人数が多い日ほど差が出ます
  • 仕分けと評価：12人のうち9人が完全に一致。ちがったのは3人
  • 理由の文の量：Flash のほうが長い（レポート全体で 13,808字 対 10,422字）。薄くはなりませんでした
  • 聞いていないこと：Flash は頼んでいないのに、明日の導入の流れ（Step 1〜3）を自分から書いてきました。Pro には、こちらから続けて聞いてやっと出てきたものです
  • 小4理科でも試しました：この章の前に載せた操作画面（提出率26/28）は、実は Flash で回したものです。主眼の推論も、未提出の2人も、Pro とまったく同じでした

公式は覚えた。r=√(a²+b²) で計算はできる。なぜそうなるかは考えていない。（五十嵐 千夏）

結論
  • まず1回試すなら Flash。速いし、仕分けはほぼ同じところに落ちます
  • 毎時間まわすなら Flash。Pro の回数を気にせず続けられることのほうが、この道具では効きます
  • 数式のある教科は、Flash に上の一言を足す。それで Pro と同じ見た目になります
  • 研究授業の記録など、1回を丁寧に残したいときは Pro。文の運びが落ち着いています
