# 研修の係に渡すカードの書き方

カードは、校内の実践一覧に1枚の入口を足すための、数行のコードです。
話した先生はコードを触りません。カードをコピーして、研修の係（一覧を作った先生）に渡すだけです。一覧に足すのは係の仕事です。手順は、このファイルの「研修の係がカードを一覧に足すとき」にあります。

## カードの形（このまま使う）

```javascript
 ,{t:'【題名】', v:'【分け方】', im:'',
  pr:'【こんなときに】',
  ar:'【これでできること】',
  fs:'【まず試すなら】',
  to:'【道具】', sc:'【校種】', ro:'【名前】', url:''}
```

- 先頭のカンマは消しません。研修の係が一覧に足すとき、前のカードとのつなぎになります。
- `im:''` と `url:''` は空のまま出します。`url` には、研修の係が、先生のページの URL をあとで入れます。
- リンクだけ置く先生のときは、`url` に先生がくれたリンクを入れます。
- 話に出てこない欄は空（`''`）にして、確かめてほしいことで聞きます。中身を作って埋めません。
- 校種は、学年から明らかなときだけ書きます。「4年」から「6年」なら小学校です。「1年」から「3年」だけで、小学校か中学校か分からないときは空にします。

## それぞれの書き方

| 記号 | 名前 | 書き方 |
|---|---|---|
| `t` | 題名 | 1枚の HTML の題名と同じにする。30字まで |
| `v` | 分け方 | 下の表から1つ |
| `pr` | こんなときに | カードに出る1行。困りごとを「〜とき。」で終える。60字まで |
| `ar` | これでできること | 試したことと、どうなったか。1文か2文。うまくいかなかったことも書いてよい |
| `fs` | まず試すなら | 1枚の「最初の一歩」を短くしたもの。1文 |
| `to` | 道具 | 下の表の名前で、カンマと半角の空白で区切る（例 `Gemini, Google Forms`） |
| `sc` | 校種 | 小学校、中学校、高等学校、特別支援学校のどれか。学年から明らかなときだけ書く |
| `ro` | 名前 | 一覧に出す名前。先生が言わなければ空（`''`） |

### 分け方の選び方

分け方は、一覧の上で実践を4つに分けて絞りこむための札です。先生に見せるときは、下の「先生に言うときの名前」で言います。

| `v` に書く値 | 先生に言うときの名前 | 選ぶとき |
|---|---|---|
| `gemini` | Geminiで考える | Gemini やプロンプトで、考えを広げた、文や問いを作った |
| `notebook` | 資料を読ませる | Gemini Notebook や NotebookLM で、資料を読ませて整理した |
| `workspace` | 校務を軽くする | フォーム、スプレッドシート、スライド、Classroom、GAS などで、校務や集計を軽くした |
| `materials` | 教材を作る | プリント、ゲーム、地域の教材など、持ち帰って使える物を作った |

迷ったら、いちばん長く使った道具で選びます。

### 道具の名前のそろえ方

一覧に道具の名前で絞りこむ仕組みがあるときは、この名前で分けます。同じ道具に別の書き方をすると、絞りこみが2つに割れます。

| 話に出た言い方 | `to` に書く名前 |
|---|---|
| ジェミニ、Gemini | Gemini |
| Gemini Notebook、NotebookLM | Gemini Notebook |
| Google フォーム、フォーム | Google Forms |
| スプレッドシート | Google Sheets |
| Google スライド、スライド | Google Slides |
| Google ドキュメント、ドキュメント | Google Docs |
| Classroom、クラスルーム | Google Classroom |
| ドライブ | Google Drive |
| Google サイト | Googleサイト |
| Google チャット | Google Chat |
| GAS、Apps Script | GAS |
| Workspace Studio | Workspace Studio |
| 画像を作るAI | 画像生成AI |

表にない道具は、先生が言った名前のまま書きます。

## 文字列の決まり

- 文字列は半角の `'` で囲みます。中の文に半角の `'` と `\` を使いません。
- 文字列の中で改行しません。
- 子どもの名前、学校名、組は入れません。

## サムネイルの絵の注文

カードの絵は、どのカードも同じ刷り方（2色の孔版印刷ふう、文字なし）でそろえます。
このスキルでは絵を作らず、別の会話で使う「注文の1行」だけを渡します。絵は急ぎません。絵のないカードでも並べられます。

注文の1行の形：

```
1枚お願いします。モチーフ：【机の上に置いてある「もの」を1つか2つ】
```

- 便利になった様子、先生が楽になった様子を描かせません。机の上に何が置いてあるか、だけを言います。
- 人の顔、文字、数字、画面のボタンは入れません。
- 例：「プリントが1枚と、赤鉛筆で大きく書かれた丸」「チェックボックスが縦に並び、右に短い棒グラフ」

先生がまだ絵の様式を Gemini に教えていないときは、新しい会話で、次の文を1回だけ貼ってから注文するよう伝えます。

```
これから、学校の先生向けのWebサイトに並べるサムネイル画像を何枚か作ります。
全部が同じ棚に並ぶので、様式を完全にそろえてください。
以下を「変えない条件」として、これ以降ずっと守ってください。

【様式】
・リソグラフ（孔版印刷）で刷ったような質感。インクのかすれ、わずかな版ズレ、紙の粒子が見える
・使う色は2色だけ。濃い藍色（#2b5fd9）と、黒に近い墨色（#15181c）。地は生成りの白
・グラデーション、光沢、ドロップシャドウ、立体感は使わない。平らな色面で描く
・輪郭線は細く、かすれている。定規で引いたような均一な線にしない
・横長16:9。中央にモチーフを1つか2つだけ置き、まわりは大きく余白をとる
・見る角度は、真上からの俯瞰か、真横。斜め45度の立体的な図にしない

【絶対に描かないもの】
・文字、数字、アルファベット、ロゴ、透かし、記号
・人物の顔
・画面のUI（ボタン、ウィンドウ枠、カーソル、吹き出しの中の文字）
・意味のない小物（観葉植物、コーヒーカップ、散らばった付箋、キラキラした光）
・写真のようなリアルさ、3DCG、アニメ絵

準備ができたら「はい」とだけ答えてください。そのあと、1枚ずつ注文します。
```

絵ができたら、Googleサイトのページに貼って公開し、画像のアドレスをカードの `im:''` に入れます。この作業も研修の係が行います。

## 研修の係がカードを一覧に足すとき

ここからは、一覧を作った先生（研修の係）のための手順です。話した先生は読まなくてかまいません。

### 一覧があるとき

校内の実践一覧を、Googleサイトの埋め込みコード（HTML）で作っていて、その中にカードを並べた部分（`[` から `];` まで）があるときの手順です。

- Step 1　先生たちから受け取ったカードを、1か所に集めます。
- Step 2　カードごとに、先生のページの URL を `url:''` の中に入れます。絵があれば `im:''` に入れます。
- Step 3　Googleサイトで一覧の埋め込みを開き、コードの編集を選びます。
- Step 4　カードの並びの終わりにある `];` の直前に、集めたカードをまとめて貼ります。カードの先頭のカンマは消しません。
- Step 5　保存して、一覧にカードが増えたかを見ます。一覧が真っ白になったときは、どこかのカードに半角の `'` が混ざっているか、カンマが抜けています。貼る前のコードに戻してから、1枚ずつ足して確かめます。

### 一覧がないとき

このスキルでは、一覧そのもののひな形は配っていません。一覧がない学校では、次のようにします。

- カードは控えとして、共有のドキュメントに貼りためておきます。あとで一覧を作るときに、そのまま使えます。
- 一覧は、Googleサイトのページの並びで代えます。先生たちのページを1つの親ページの下に入れ、ページの名前を1枚の題名にそろえると、サイトの横のメニューがそのまま一覧になります。
- 親ページには、カードの「こんなときに」（`pr`）の1行を、ページへのリンクと一緒に並べてもかまいません。
