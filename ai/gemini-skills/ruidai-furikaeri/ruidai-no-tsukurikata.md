# 類題の作り方

元の問題と同じ解き方で、数と場面だけを変えた問題を作るための決まりです。
授業のあとにすぐためして、自分で丸つけをするための問題なので、その時間に習ったことだけでとける問題にします。

## 1. 同じ形にする

はじめに、元の問題の「解き方の形」を1行で決めます。

- 例：2けた÷1けた、あまりあり、商は2けた、答えのたしかめまで
- 例：2けた×1けた、一の位でくり上がり1回
- 例：小数のたし算、位をそろえて計算、答えの終わりの0を消す

| 変えてよいもの | 変えないもの |
|---|---|
| 数 | 計算の種類（たし算、ひき算、かけ算、わり算） |
| 場面（何の話か） | 手順の数（筆算の段の数、式の数） |
| ものの名前 | 聞き方（「1人分は何まいで、何まいあまりますか」など） |
| 同じ量の中での単位（まい、こ、本） | くり上がり、くり下がりの回数（1問目だけは、下の2のとおり例外） |
| | 商に0が立つかどうかと、その位置 |

## 2. ならべ方と数

- 3問前後にします。ふつうは、計算2問と文章題1問です。
- 1問目をいちばんやさしくし、2問目と3問目を元の問題と同じむずかしさにします。やさしい問題から始めると、手が止まりにくくなります。
- 1問目だけは、計算の種類と聞き方と手順の数を変えずに、くり上がりやくり下がり（わり算では、とちゅうの位のあまり）が出ない数にしてよいです。変えたところは先生用の紙に書きます。
- 計算だけをむずかしくしません。数を大きくするのは、元の問題と同じけた数までです。
- 1ページに入らないときは、問題を1つへらします。計算を書く場所はせまくしません。

## 3. 場面

- 子どもの生活の中から選びます（給食、休み時間、図書室、そうじ、係の仕事、学級の行事など）。
- 問題文に人の名前は入れません。「同じ数ずつ分けます」「みんなで何人ですか」のように書きます。
- 数が場面に合うようにします。ありえない数（1人に色紙を300まい配るなど）にしません。
- お金の問題は、その学年で習ったお金の計算の範囲にします。

## 4. 写さない

- 教科書の本文や問題、市販のテスト、ドリルの問題は写しません。「何を問うか」だけを借り、数と場面と文は作り直します。
- 先生が貼った元の問題の数を、そのまま使いません。計画の中に出てくる例の数（教科書の例の数かもしれないもの）も使いません。
- 問題文は、自分の言葉で一から書きます。

## 5. 単元ごとに確かめること

| 単元の種類 | 数を決めるときに確かめること |
|---|---|
| たし算、ひき算の筆算 | くり上がり、くり下がりの回数を元の問題とそろえる。とちゅうの位の0の有無もそろえる |
| かけ算の筆算 | くり上がりが、どの位で何回あるかをそろえる |
| わり算（わり切れる） | かけ算で戻して、ちょうどになることを確かめる |
| わり算（あまりあり） | あまりがわる数より小さいこと。あまりが0にならないこと。とちゅうの位であまりが出るか（85÷3なら8÷3であまり2）を元の問題とそろえる |
| 商に0が立つわり算 | 0が立つ位を元の問題とそろえる |
| 小数 | 小数点の位置。答えの終わりの0の扱い（0.50なら0.5と書く）を元の問題とそろえる |
| 分数 | 答えが約分できるかどうか、帯分数か仮分数かを、元の問題と計画にそろえる |
| 単位のある量 | 単位を直す問題かどうかを元の問題とそろえる |
| 図形（長さ、角、面積） | 図を測らせない。長さや角度は、図の中に数で書く |
| 文章題 | 式が1つの問題か、2つの問題かを元の問題とそろえる |

## 6. 検算のやり方（答えを書く前に、必ず）

検算 Step 1　ふつうに計算します。筆算なら、各段の数を書きます。
検算 Step 2　はじめとは別のやり方で、もう一度計算します。下の表のやり方を使います。
検算 Step 3　2つの答えが合わないときは、その問題の数を作り直し、検算 Step 1 からやり直します。
検算 Step 4　上の「5. 単元ごとに確かめること」の条件に合っているかを見ます。
検算 Step 5　検算の式と結果を、先生用の紙に書きます。
検算 Step 6　紙に書いた答えと、検算の結果を、1問ずつ見比べます（写しまちがいを見つけるため）。

| 計算 | 別のやり方 |
|---|---|
| たし算　a+b=c | c−b を計算して、a になるか |
| ひき算　a−b=c | c+b を計算して、a になるか |
| かけ算　a×b=c | a を分けて計算する（23×4 なら 20×4+3×4）。または c÷b が a になるか |
| わり算　a÷b=q あまり r | b×q+r が a になるか。r が b より小さいか |
| 小数の計算 | 小数点をとった整数で計算し、あとから位を戻す |
| 分数の計算 | 通分した形でもう一度計算する。約分した答えを、元の分母に戻して見比べる |
| 文章題 | 答えを問題文に戻して読み、場面に合うか（人数が小数になっていないかなど）を見る |

## 7. つまずきやすいところ

先生用の紙に、問題ごとに1行だけ書きます。
「不注意」「練習不足」とは書きません。手順のどこで止まりやすいかを書きます（例：一の位のくり上がりの1をたしわすれる）。
