# 教材研究のまとめ　4年 理科「とじこめた空気と水」（全6時間）

## 1. 学習指導要領での位置

- 学年と項目：第4学年 A物質・エネルギー (1) 空気と水の性質　ア(ｱ)(ｲ)、イ
- 解説の文（解説 理科編 p.47）
  - 「閉じ込めた空気を圧すと，体積は小さくなるが，圧し返す力は大きくなること。」
  - 「閉じ込めた空気は圧し縮められるが，水は圧し縮められないこと。」
- 前の学年とのつながり：第3学年でつながる内容は、貼られた文には書かれていません。解説 理科編 第2章 第2節「理科の内容構成」で確かめます。【要確認】
- 次の学年とのつながり：解説 p.47 には、この内容が第6学年のA(1)「燃焼の仕組み」の学習につながると書かれています。
- 同じ学年の次の単元：計画では、次は「物の体積と温度」です。この単元の結論を、次の単元の第1時で思い出させます。

## 2. 解説が示している指導のポイント

1. 空気と水のちがいを、手ごたえなどの体で感じたことをもとに調べます。「空気と水の性質の違いを，力を加えたときの手ごたえなどの体感を基にしながら調べるようにする。」（p.48）
2. 力を加える前と後の、空気や水の体積の変わり方を、図や絵で表して説明する活動を大切にします。（p.48）
3. 学んだことを、空気や水の性質を使ったおもちゃや道具の仕組みに当てはめます。日常生活では、ボールやタイヤを取り上げることが示されています。（p.48）
4. 予想や仮説は、学習したことや生活の体験をもとに、わけをつけて考えさせます。（p.47）
5. 容器がこわれたり、一部が飛び出したりして、顔や体に当たらないように、安全に気をつけさせます。（p.48）

## 3. 子どもがつまずきやすいところ

| つまずき | その場の問い返し | 手立て |

| 予想にわけが書けない | 「昨日、空気でっぽうを打ったとき、どうだった？」 | 体験をわけにしてよいと伝えます。 |

| 水も縮むと思いこんでいる | 「どこまでおしたら、目もりが動くかな？」 | 思いきりおさせます。動かないことを、予想とくらべさせます。 |

## 4. 準備と安全

| 物 | 数 | 前もって確かめること |
|---|---|---|
| 空気でっぽう | 16 | 数と、玉の在庫を確かめます。 |
| 注射器（大） | 16（各班2本と予備） | ピストンが固まっていないか、届いたら1本ずつ動かして確かめます。 |
| ゴム板（注射器の先をふさぐ） | 8 | 水がもれないかを確かめます。もれると「水も縮んだ」に見えます。 |
| 記録用紙（手ごたえの欄つき） | 児童数の2倍と予備 | 手ごたえの欄が印刷されているかを確かめます。 |
| トレー、ぞうきん | 8組 | 水の実験の前に、班に配れるかを確かめます。 |
| 水そう | 2 | 水の実験の前に、水を入れておきます。 |
| 身の回りの物（ボール、うき輪など） | 数点 | 第6時に見せる物を決めておきます。 |

安全の約束（子どもに言う言葉）

- 「空気でっぽうも注射器も、先を人に向けません。」
- 「打つ向きは、みんなで1つにそろえます。」
- 「玉は、口に入れません。」
- 「おしているときに、急に手を放しません。ピストンが飛びます。」
- 「力いっぱいおしません。注射器がわれます。動かないと分かったら止めます。」

## 5. 授業を深める教材のアイデア

1. **身の回りの物で、空気と水の使い分けを考える**（第6時）
   ボール、タイヤ、うき輪、エアクッション、水でっぽうを見せます。「なぜ空気を使うのか」「なぜ水を使うのか」を、1つ選んで説明させます。
2. **おす前とおした後を、絵でかきくらべる**（第4時、第6時）
   注射器の中の空気と水が、おす前とおした後でどうなっているかを、絵でかかせます。空気と水の絵を横にならべると、ちがいを言葉にしやすくなります。
3. **算数の「かさ」とつなぐ**（第3時）
   注射器の目もりが mL で書かれているときは、算数の第2学年で学習した、かさの単位とつなげて読みます。目もりの単位は【要確認】です。

先行事例を探すときの言葉

- 「空気と水の性質 4年 指導案」
- 「とじこめた空気 導入 空気でっぽう」
- 「注射器 手ごたえ 記録 4年 理科」
- 探す場所：都道府県や市の教育センター、教育研究会、大学の附属小学校、教科書会社の授業の資料
