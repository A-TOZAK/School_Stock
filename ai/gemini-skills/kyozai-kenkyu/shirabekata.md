# 学習指導要領の調べ方

教材研究のまとめを作るときに使う、学習指導要領と解説の調べ方です。
ここにある章の名前と領域の名前は、文部科学省の「小学校学習指導要領（平成29年告示）解説」の各教科編の目次と本文で確かめたものです。
ページ番号は、版によってずれることがあるので、ここには書いていません。

## 1. 番号の書き方

単元の位置は、学年、領域、項目の番号の順で書きます。

| 教科 | 書き方の例 |
|---|---|
| 理科 | 第4学年 A物質・エネルギー (1) ア(ｱ)(ｲ)、イ |
| 算数 | 第4学年 A数と計算 (3) ア(ｱ) |
| 国語 | 第3学年及び第4学年 〔思考力，判断力，表現力等〕 C読むこと (1) ア |
| 社会 | 第4学年 (1) ア(ｱ) |

- 例の番号は、書き方の形を示すためのものです。実際の単元の番号は、添付されたPDFか貼られた文で確かめます。確かめられないときは【要確認】をつけます。
- (ｱ)(ｲ) は、半角のカタカナを（）で囲んだ形です。解説の本文では ⑴ のように丸い括弧の数字で書かれていることがあります。資料では (1) と書いてかまいません。

## 2. 教科ごとの領域の名前

| 教科 | 領域の名前 |
|---|---|
| 算数 | A数と計算、B図形、C測定（第1学年から第3学年）、C変化と関係（第4学年から第6学年）、Dデータの活用、〔数学的活動〕 |
| 理科 | A物質・エネルギー、B生命・地球（理科では「内容区分」と呼びます） |
| 国語 | 〔知識及び技能〕と〔思考力，判断力，表現力等〕。〔思考力，判断力，表現力等〕は、A話すこと・聞くこと、B書くこと、C読むこと |
| 社会 | 領域の文字はありません。学年ごとに、内容が (1) (2) の番号で並びます |
| 音楽 | A表現、B鑑賞、〔共通事項〕 |
| 図画工作 | A表現、B鑑賞、〔共通事項〕 |
| 家庭 | A家族・家庭生活、B衣食住の生活、C消費生活・環境 |
| 体育 | 学年のまとまりごとに、Aから始まる運動の領域が並びます。第3学年からは「G保健」があります |

- 国語、音楽、図画工作、体育は、第1学年及び第2学年、第3学年及び第4学年、第5学年及び第6学年のように、2つの学年をまとめて内容が書かれています。
- 理科の区分を「粒子」「エネルギー」と書かないでください。「粒子」「エネルギー」「生命」「地球」は、内容を整理するときの柱の名前で、区分の名前ではありません。

## 3. 解説のどの章を見るか

| 教科 | 学年の内容が書かれた章 | 指導計画と内容の取扱いの章 | つながりを見る場所 |
|---|---|---|---|
| 算数 | 第3章 各学年の目標及び内容 | 第4章 指導計画の作成と内容の取扱い | 第2章 第2節 の「各領域の内容の概観」 |
| 理科 | 第3章 各学年の目標及び内容（第3学年から） | 第4章 指導計画の作成と内容の取扱い（事故防止、薬品などの管理を含む） | 第2章 第2節「理科の内容構成」 |
| 国語 | 第3章 各学年の内容 | 第4章 指導計画の作成と内容の取扱い（教材についての配慮事項を含む） | 第2章 第2節「国語科の内容」 |
| 社会 | 第3章 各学年の目標及び内容（第3学年から） | 第4章 指導計画の作成と内容の取扱い | 第2章 第2節「社会科の内容構成」 |
| 生活 | 第3章 生活科の内容 | 第4章 指導計画の作成と内容の取扱い、第5章 指導計画の作成と学習指導 | 第5章 の「幼児期の教育や中学年以降の学習との関わり」 |
| 音楽 | 第3章 各学年の目標及び内容 | 第4章 指導計画の作成と内容の取扱い | 第2章 第2節「音楽科の内容」 |
| 図画工作 | 第3章 各学年の目標及び内容 | 第4章 指導計画の作成と内容の取扱い（安全指導を含む） | 第2章 第2節「図画工作科の内容」 |
| 家庭 | 第2章 第3節 家庭科の内容（第5学年と第6学年） | 第3章 指導計画の作成と内容の取扱い（実習の指導を含む） | 第2章 第2節「家庭科の内容構成」 |
| 体育 | 第2章 第2節 各学年の目標及び内容 | 第3章 指導計画の作成と内容の取扱い | 巻末の「参考　小学校及び中学校の領域別系統表」 |
| 外国語活動 | 第1部 第2章 外国語活動の目標及び内容（第3学年と第4学年） | 第1部 第3章 指導計画の作成と内容の取扱い | 第1部 第1章 総説 |
| 外国語 | 第2部 第2章 外国語科の目標及び内容（第5学年と第6学年） | 第2部 第3章 指導計画の作成と内容の取扱い | 第2部 第1章 総説 |
| 特別の教科 道徳 | 第3章 第2節 内容項目の指導の観点 | 第4章 指導計画の作成と内容の取扱い | 第3章 第1節 内容の基本的性格 |
| 総合的な学習の時間 | 第3章 各学校において定める目標及び内容 | 第4章 指導計画の作成と内容の取扱い | 第5章、第6章（指導計画と単元計画） |
| 特別活動 | 第3章 各活動・学校行事の目標及び内容 | 第4章 指導計画の作成と内容の取扱い | 第2章 第2節 |

- 「解説が示している指導のポイント」は、学年の内容が書かれた章の中で、その項目の説明のあとに書かれていることが多いです。あわせて、指導計画と内容の取扱いの章も見ます。
- 総合的な学習の時間は、学年ごとの内容が決められていません。学校が定める目標と内容に当たるので、「学習指導要領での位置」には、学校の全体計画のどこに当たるかを書き、【要確認】をつけます。

## 4. 解説の文がないときの書き方

- 「」の引用はしません。項目の番号と、あなたの言葉での要約だけを書き、行の終わりに【要確認】をつけます。
- 書き方の例：「第4学年 A数と計算 (3) 整数の除法に当たると考えられます。わり算の筆算の仕方を、位ごとに考えて説明することが中心です。【要確認】」
- 「1. 学習指導要領での位置」の最後の行に、「解説の文は、貼られていないので引用していません。解説のPDFを添付するか、Gemini Notebook で確かめた文を貼ると、引用つきで作りなおします。」と書きます。

## 5. Gemini Notebook で解説を確かめる手順（先生に伝えるとき）

1. Gemini Notebook で「新しいノートブック」を作ります。
2. 「ソースを追加」の「ファイルをアップロード」から、学習指導要領解説のPDFを入れます。PDFは、文部科学省の「小学校学習指導要領解説」のページにあります。使う教科の編を入れます。
3. ノートブックの中で、「4年算数のわり算の筆算は、学習指導要領のどの項目に当たりますか。解説の文をページの番号つきで抜き出してください」のように聞きます。答えには、解説のどこから引いたかが示されます。
4. 示されたページをPDFで開き、文が同じかを確かめます。
5. 新しい会話でこのスキルを呼び、単元の計画の下に「解説の文」として貼ります。スキルとノートブックは、別の会話で使います。

## 6. 先行事例の探し方

先行事例は、先生がこれから探すための手がかりとして書きます。

- 探す場所の種類：都道府県や市の教育センター、教育研究会、大学の附属小学校、教科書会社の授業の資料、教育委員会が出している指導案集
- 検索の言葉の作り方：「単元名」「学年と教科」「指導案」を組み合わせます。導入の工夫を探すときは「導入」、つまずきを探すときは「つまずき」や「誤答」を足します。
  - 例：「空気と水の性質 4年 指導案」「とじこめた空気 導入 空気でっぽう」「わり算の筆算 4年 つまずき 商に0」
- URLの決まり：
  - 実在を確かめられないURLは書きません。記憶から思い出したURLは書きません。
  - この会話の中で検索し、ページの中身を読めたときだけ書きます。書くときは、後ろに「（先生が開いて確かめてください）」と書きます。
  - 指導案の文を写さず、どんな工夫かを自分の言葉で1行にまとめます。
